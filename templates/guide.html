🎯 系统概览

AI小课堂是一个面向4年级学生的互动教学系统，包含三大核心功能：

  • 3D数字人"小艾" — AI助教姐姐，用语音跟同学们互动
  • 元宇宙3D抽奖 — 43位同学球面头像旋转 + 语音指令抽取
  • 语音识别 + AI对话 — 支持麦克风语音问答，用 DeepSeek 生成回复

🚀 启动与关闭

启动系统

打开终端，进入项目目录，执行：

cd /Users/dennisduan/Documents/AI_Class_4/ai-class
./start.sh

脚本会自动检查 Python、Flask 依赖，检测端口占用，启动后在浏览器自动打开系统页面。

服务启动后浏览器访问：http://localhost:5000

关闭系统

在终端中执行：

cd /Users/dennisduan/Documents/AI_Class_4/ai-class
./shutdown.sh

脚本会查找占用 5000 端口的进程并安全关闭，可选择是否清理运行日志。

⚠️ 如果修改了代码需要重启，请先 shutdown 再 start。

🎤 语音交互

系统支持两种语音输入模式（需要 Chrome 浏览器）：

  • 单次对话 点击后说一句话，识别后自动停止
  • 持续监听 点击后会一直监听，每次识别到说话后自动再次开始
  • 停止 随时停止语音监听


语音会做两件事：

  • 正常问答 普通语音会发给 DeepSeek AI 回答，小艾会回复你
  • 语音指令 特定指令会触发系统动作（见下节）
💡 课堂建议使用 持续监听 模式，老师只需说话，无需手动操作。

📣 语音指令大全

🎲 开始抽取同学

触发 3D 抽奖旋转动画，然后一次抽取 N 位同学并在屏幕中央展示中奖者姓名。

"开始抽取同学" — 只这一句话会触发抽奖，其他普通语音不会触发。

🔢 设定一次抽取N个

设定下次抽取的人数，默认值是 5 人。

说 "设定一次抽取3个" — 系统回复 "收到设定指令，下次抽取人数为3人"。

数字可以改成任意正整数（1 ~ 43）。

设定后右上角徽章会实时更新。

🔄 不重复抽取

已中奖的同学 不会再次被抽中。当所有 43 人都抽完后，系统自动复位，全部同学重新参与抽取。

也可以点击右上角 🔄 重置抽奖 按钮手动复位。

🌟 3D 抽奖界面说明

  • 头像球面分布 — 43 位同学的头像均匀分布在球体表面，匀速自转
  • 抽奖中 — 球体加速旋转，屏幕底部显示"抽奖进行中…"
  • 中奖展示 — 中奖的 N 个头像移动到屏幕中央并放大，播放欢呼音效
  • 状态显示 — 底部显示"已抽取 X/Y 人"，实时更新
  • 重置按钮 — 右上角橙色按钮，一键清空中奖记录重新开始

⚙️ 配置 & 二次开发

修改学生名单

编辑 app.py 中的 students 列表，替换为真实姓名和头像地址：

students = [
{"id": 1, "name": "张三", "avatar": "头像URL"},
{"id": 2, "name": "李四", "avatar": "头像URL"},
...
]

修改默认抽取人数

编辑 app.py 中 draw_count = 5 的数值。

更换 DeepSeek API Key

编辑 app.py 中的 DEEPSEEK_API_KEY 变量。

更换端口

编辑 app.py 最后一行 port=5000，同步修改 start.sh 和 shutdown.sh 中的 PORT=5000。

🔧 常见问题

打开页面后3D不显示？

  • 确认使用 Chrome 浏览器
  • 检查网络，Three.js CDN 是否加载成功
  • 刷新页面重试

语音识别没反应？

  • 必须用 Chrome，Safari/Firefox 不支持 Web Speech API
  • 检查浏览器麦克风权限是否已允许
  • 点击"停止"后再点击"单次对话"重新开始

服务启动失败？

  • 检查 5000 端口是否被其他程序占用：lsof -i :5000
  • 检查 server.log 日志文件查看错误信息
  • 确认 Python 3.8+ 已安装：python3 --version

AI 对话没有回复？

  • 检查 DeepSeek API Key 是否有效
  • 检查网络是否能访问 api.deepseek.com
  • 普通语音问答依赖 API，不可用时会自动回复"我听到啦：……"
